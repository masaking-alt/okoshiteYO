okoshiteYO! 仕様書

第１章 テーマ
・絶対起こすマンなアラームアプリ。シンプルで使いやすく、寝坊を防ぐ。

第２章 ターゲット
・朝起きられない学生
・絶対に遅刻できない社会人
・年齢層 20〜50歳の元気な人

第３章 目的（解決する課題）
・普通のアラームでは起きられない
・二度寝してしまう
・起きてもすぐに活動できない

第４章 セールスポイント・差別化
・既存の目覚ましアプリより超シンプルで分かりやすい

第５章 メイン機能
第１節 アラーム設定
・回転式 UI とキーボード入力で設定可能
第２節 アラームの止め方
・計算問題で解除
・スマホをシェイクで解除
・写真（位置情報付き）で解除
・写真が使えない場合は計算またはシェイクに自動フォールバック
第３節 設定
・曜日指定で
第４節 スヌーズ
・無し（絶対起こす方針）
第５節 補助機能
・無し

第６章 画面構成
・ホーム画面
・設定画面
・アラーム追加画面
・アラーム発火画面（計算問題）
・アラーム発火画面（シェイク）
・アラーム発火画面（写真）

第７章 使用技術
・UI: React Native
・システム: Kotlin（Android 純正 AlarmManager API を利用）

第８章 権限とOSバージョン
第１節 必須権限・設定（アラーム作成時に確認）
・SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM（API31+ 正確なアラーム許可）
・POST_NOTIFICATIONS（API33+ 通知 runtime 権限）
・WAKE_LOCK（Manifest のみ）
・ACCESS_NOTIFICATION_POLICY（DND中でも鳴らすため設定画面へ誘導）
・フルスクリーン通知＋Activityで表示（Overlay 権限は使わない）
第２節 選択的権限（解除方法選択時に確認）
・CAMERA + ACCESS_FINE_LOCATION（位置付き写真解除。どちらか拒否なら写真ミッションは使わず計算/シェイクに切替）
・ストレージ権限は不要（音源選択は SAF、写真はアプリ内保存のみ）
第３節 リクエストのタイミング
・アラーム作成時: 正確アラーム、通知、DND貫通をまとめて案内。拒否時は保存をブロックするか、DNDのみ例外扱い（DND拒否時は「DND中は鳴らない」と明示）。
・解除方法選択時: 写真モードを選んだ瞬間に CAMERA+位置をリクエスト。拒否ならその場で計算/シェイクへフォールバックしてから保存。
・発火時に権限ダイアログは出さない。
第４節 OSバージョン方針
・minSdk 24、targetSdk は最新
・API31 (Android 12): 正確アラーム許可が必要。android:exported をコンポーネントに明示。
・API33 (Android 13): 通知は POST_NOTIFICATIONS が runtime 権限。READ_MEDIA_IMAGES は使わない前提。SAF のみで音源選択。

第９章 バッテリー最適化とタスクキル時の挙動
・バッテリー最適化解除（ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS）は初期案内なし。遅延が疑われる場合や「信頼性向上」トグルをオンにしたときだけ誘導。
・発火フロー: AlarmManager（setExactAndAllowWhileIdle 等）→ BroadcastReceiver → Foreground Service（startForeground で即通知、必要なら短時間 WakeLock）→ フルスクリーン Activity（fullScreenIntent, setShowWhenLocked, setTurnScreenOn）。プロセスがキルされていても起動。

第１０章 データ保持・プライバシー
・写真は解除用にのみアプリ内キャッシュへ保存し、解除後削除。外部保存なし。
・位置情報は撮影時のみ取得し、保存しない。
・ログに個人情報を含めない。

第１１章 アラーム音源
・デフォルト音源はアプリ同梱。
・端末の音楽を使いたい場合は SAF（ACTION_OPEN_DOCUMENT, audio/*）で取得した URI を persistable URI として保存し、再生時に ContentResolver で開く。追加権限不要。
・ストリーミングサービス（Spotify/YouTube Music/LINE MUSIC 等）は非対応（バックグラウンド自動再生が保証できないため）。

第１２章 写真＋位置情報ミッションの運用
・位置付き撮影が前提。CAMERA または ACCESS_FINE_LOCATION が拒否された場合は写真ミッションをスキップし、計算またはシェイクにフォールバック。
・UIで「写真解除にはカメラ＋位置の許可が必要」と明示する。
