# アラーム最前面表示の実装記録

アラーム発火時は `AlarmReceiver` から `AlarmForegroundService` を起動し、アラーム音、バイブレーション、フルスクリーン通知を開始する。解除画面は `AlarmRingingActivity` を `showWhenLocked` と `turnScreenOn` 付きで起動し、React 側には `entryPoint: alarm` と発火ペイロードを渡す。

保存時は次の端末設定を確認する。

- 正確なアラームの許可
- 通知の許可
- Android 14 以降の全画面通知の許可

不足している場合は保存処理を止め、対応する端末設定画面へ誘導する。設定画面にも同じ導線を置く。

端末条件として、Android 14 以降では全画面通知の許可が拒否されていると、スリープ中やバックグラウンド中の解除画面起動が通知表示に留まる場合がある。おやすみモード中は端末の通知ポリシーが優先されるため、必要に応じて端末側でアラーム通知の扱いを確認する。
