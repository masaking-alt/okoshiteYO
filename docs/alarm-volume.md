# アラーム音量の実装記録

アラームごとの音量は `0.2` から `1.0` の比率で保存する。既存アラームや不正な保存値は `0.8` に補正する。

発火時は保存値を端末のアラーム音量へ反映する。再生開始前の端末アラーム音量はサービス内で保持し、停止時に復元する。端末側の制約で音量変更が拒否された場合は、アプリ内再生音量へ同じ比率を設定する。

端末本体の音量設定とは、発火中だけ一時的に連動する。マナーモードでも端末のアラーム音量ストリームを使う。おやすみモード中は通知ポリシーや端末設定の影響を受けるため、アプリ単独では必ず鳴動を保証しない。通知チャンネルはおやすみモードのバイパスを要求する設定だが、端末側で許可されていない場合は利用者の設定が優先される。
